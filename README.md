# LunaFlow · 极简经期记录 AI 小程序

> **让每位女性更懂自己的周期**
>
> 一个融合 **数据记录 · 健康关怀 · 商业服务** 的女性全周期健康微信小程序

## 项目概述

LunaFlow 是一款面向中国大陆成年用户的微信小程序,以"极简记录 + AI 整理"为核心体验,通过主动预约和短文案通知帮助用户**少忘一件事、少填几项**。

### 一句话定位

> 简单事情一键记 · 复杂感受一句话整理 · 需要时整理给你看

## 核心设计原则

### 五项产品底线(来自审查文档 §1.3)

1. **先确认,再保存或分享** - AI 不替用户编造症状
2. **付款不等于查看权** - 付款/分享/AI/通知分别管理
3. **关怀不等于监控** - 不提供实时行踪、恋爱打分
4. **会员不等于自动续费** - 首阶段测试单次月卡
5. **权益不等于导购干扰** - 健康记录与商品营销分离

### 商业模式核心

- **付费设计**:免费基础 + 9.9 元月卡 + 自愿连续包月
- **用品权益**:每账期用户自选一张合作商家券
- **单位经济**:示例贡献 个人 6.4 元 / 关怀 10.4 元(需实测)
- **验证路径**:任务原型 → 单次月卡 → 观察续购 → 小额试投

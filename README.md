# LunaFlow · 极简经期记录与用品补给

> 记录周期，轻松补给。

LunaFlow 面向中国大陆成年用户，规划提供极简经期记录、AI 整理、自愿关怀和用品补给。本仓库保存产品方案、市场参考和 PPT 网页；这些内容不代表产品已经上线、供应已经落实或相关能力已经获批。

## 当前商业验证方向

**用品负责促成首单，补货服务促进主动复购，经期工具与数字会员分别验证价值。**

- 首轮候选：一份品牌、规格、片数明确的原包装经期用品组合，暂按 **39.9 元／次**测算。
- 成交链路：广告 → 商品详情 → 一次付款 → 履约；填写经期、体验 AI 和绑定伴侣不作购买前置条件。
- 再次购买：保存常用组合、用户自选提醒、自主确认付款；首轮不依赖自动扣款或用户遗忘收益。
- 经济假设：每单投流前贡献 **12.9 元**，仍须扣获客与固定成本；所有价格、成本均待真实供应和订单验证。
- 小额试验：增量费用上限 **2,000 元**，另备约 **1,500 元**周转资金；不包含从零开发小程序的人工成本。

完整口径见 [首发补给包与主动复购验证方案 V1.2](docs/report/LunaFlow_首发补给包与主动复购验证方案_V1.2.md)。

### 查看与演示

直接用浏览器打开 `docs/cover.html`，并保留相邻的图片和研报目录。也可以在仓库根目录启动本地 HTTP 服务：

```bash
python3 -m http.server 8000
```

然后访问 [本地 PPT 网页](http://localhost:8000/docs/cover.html)。

- 使用页面目录跳转，使用左右方向键翻页。
- 切换阅读模式，可连续浏览全部内容。
- 使用页面打印入口或浏览器打印，输出完整讲稿或 PDF。
- 调研页可查看研报目录、原始材料及放大图稿。

## 产品边界

1. AI 整理先由本人确认，再保存或分享，不替用户编造症状或作医疗结论。
2. 付款、关系绑定、分享授权、AI 处理与消息订阅分别管理；付款不授予健康数据查看权。
3. 基础记录不依赖购买、伴侣参与或营销授权；健康记录与商品营销分离。
4. 补货时间由用户选择，不直接以周期预测或症状触发营销。
5. 商品复购、工具使用和数字会员付费分别统计；任何一项成立都不自动证明另两项成立。

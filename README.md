# LunaFlow · 极简经期记录与用品补给

> 记录周期，轻松补给。

LunaFlow 面向中国大陆成年用户，规划提供极简经期记录、AI 整理、自愿关怀和用品补给。本仓库保存产品方案、市场参考和 PPT 网页；这些内容不代表产品已经上线、供应已经落实或相关能力已经获批。

## 当前开发基线

**极简经期工具＋AI 个人回顾＋月度护理权益，组合为可持续验证的会员服务。**

当前开发依据：[小程序技术 PRD V1.0](docs/report/LunaFlow_小程序技术PRD_V1.0.md)。

配套设计：[20页UI设计稿索引](docs/UI/README.md) · [UI/UX详细说明](docs/UI/UI_UX_SPEC.md)。

- 首发以“省事补给型”为主要需求假设，以“记录回顾型”作对照；人群与经营效果仍待真实投放验证。
- 产品导航：今天／回顾／权益／我的。广告可直接进入服务购买，也可先体验工具；购买不强制填写经期信息。
- 月度权益：每个已付服务账期一次，用户自行选择并领取；正常未领到期与平台故障补救分别处理。
- 支付方式：支持单期主动付款与续购；自动续费独立设计，取得对应商户准入、模板及联调条件后启用。
- PRD 包含 32 项功能、20 个页面交互规格、46 类事件和 39 条验收场景，以及接口、数据模型、运营后台与实施阶段。
- 价格、供应商、成本、获客与留存指标均待验证，不沿用历史方案中的测算值作为当前承诺。

人群与研究依据见下方文档目录。历史[首发补给包与主动复购验证方案 V1.2](docs/report/LunaFlow_首发补给包与主动复购验证方案_V1.2.md)保留作比较参考；当前功能范围和实现规则以技术 PRD 为准。

### 查看与演示

直接用浏览器打开 `docs/cover.html`，并保留相邻的图片和研报目录。也可以在仓库根目录启动本地 HTTP 服务：

```bash
python3 -m http.server 8000
```

然后访问 [本地 PPT 网页](http://localhost:8000/docs/cover.html)。

- 使用页面目录跳转，使用左右方向键翻页。
- 切换阅读模式，可连续浏览全部内容。
- 使用页面打印入口或浏览器打印，输出完整讲稿或 PDF。
- 调研页可查看研报目录、原始材料及放大图稿。

## 产品边界

1. AI 整理先由本人确认，再保存或分享，不替用户编造症状或作医疗结论。
2. 付款、关系绑定、分享授权、AI 处理与消息订阅分别管理；付款不授予健康数据查看权。
3. 基础记录不依赖购买、伴侣参与或营销授权；健康记录与商品营销分离。
4. 补货时间由用户选择，不直接以周期预测或症状触发营销。
5. 首付、自动续费、主动续购、工具使用、权益领取与成本后贡献分别统计；自动扣款、主动领取和主动复购不混为一项。

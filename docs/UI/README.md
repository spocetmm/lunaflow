- [小程序技术PRD V1.0](../report/LunaFlow_小程序技术PRD_V1.0.md)：功能、业务规则、数据、接口及完整验收基线。

## 使用约定

1. 图片是高保真视觉评审稿；交互与业务以技术PRD为准。实现时使用真实组件和可访问文本，统一字体、图标、间距及控件状态。
2. ¥39.90/月、AI次数、品牌A/B/C、商品规格、地址、日期、发货时效及客服时间均为设计示例，不代表正式定价、合作或承诺。
3. 默认单期主动购买、到期自行续购。U16只展示代扣能力获批且用户已独立签约后的条件交互。
4. 主要按钮统一使用`#B74752`白字（纯色组合对比约5.20:1）；原`#E97875`仅作装饰。旧图中的细节差异不得形成第二套实现组件。
5. 每张画板仅2个视图，不等于全部状态。全量状态以UI/UX说明第7、9、10节及技术PRD第6.2节为准；均须按PRD和统一状态组件实现。本次交付不表示小程序已实装。
6. 只收录最终校对版；早期草稿、被替代版本和其他主题图片不在此目录。

## 评审顺序

- 购买：U01 → U02 → U03。
- 记录与回顾：U04 → U05，或U06 → U07；U08 → U09。
- 护理领取：U10 → U11 → U12 → U13。
- 会员与售后：U14 → U15；符合条件时进入U16；订单退款进入U17。
- 通用服务：U18提醒、U19隐私、U20客服。
- 首次使用与工具恢复：S01 → S02，记录来源与冲突S03，额度和异步任务S13。
- 购买与领取恢复：S04—S08；隐私任务S09/S10；预约及客服任务S11/S12；续购及取消未知S14。
- 关键业务分支：S15/S16退款与取消在途收费；S17删除结果；S18库存；S19提醒能力；S20日期校验；S21回顾降级；S22签约状态。

取消续费与退款独立；提前续购不增加当期领取次数；退款申请受理前仍可领取，受理后按PRD冻结相关资格；缺货或平台故障进入补救。

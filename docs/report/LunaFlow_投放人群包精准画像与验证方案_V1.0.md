## 1. 首发定位与产品前提

**首发定位：自己购买经期护理用品，希望记录更简单、补给更省事，并可能愿意为两者的组合持续付费的成年女性。**

拟议服务由三部分构成：轻量经期记录工具、基于个人记录的 AI 回顾、多品牌护理权益。当前商业方案为按月扣款，每个权益周期允许用户自行领取一次护理组合，当期未领取不补发。具体收费、周期、取消、退款和履约规则仍需确定，不能把这个方案视为已上线、已获准或已验证盈利。

主动复购是希望观察到的更强需求信号。自动扣款、主动领取、主动再次下单分别记录，不用其中一种替代另一种。未领取带来的成本变化纳入经营分析，但不预设某类人“容易忘领”，也不以此定义投放对象。

## 2. 三类需求画像与优先级

| 编号 | 需求画像 | 主要购买动机假设 | 验证重点 | 优先级 |
|---|---|---|---|---|
| P1 | 省事补给型 | 简单记录，少做选购比较，领取适合自己的常用组合 | 是否认可工具与实物的组合价值 | 首发主定位 |
| P2 | 记录回顾型 | 把零散记录整理成清楚、可核对的个人历史 | 回顾是否产生持续使用价值，护理权益能否补充价值 | 首轮对照 |
| P3 | 商品划算型 | 品牌、规格、数量和到手成本有吸引力 | 商品优惠减弱或家中有库存时是否仍续费 | 后置对照 |

三类画像可能重叠：同一个人既想省事，也关心价格，并偶尔回看记录。它们是需求解释，不是天然互斥的广告定向包。只有平台支持互斥实验、或内部采用明确且预先约定的分组规则时，才能比较互斥组表现。

## 3. P1 省事补给型完整画像

### 3.1 可直接使用的描述

首轮以 **22—35 岁成年女性**作为起始测试范围，在供应商能够稳定配送的地区寻找本人采购经期用品的用户。她有常用品牌和规格，曾用日历、备忘录或经期工具记录，但可能时断时续；希望随手记、少填写，并减少重复选购的步骤。她是否愿意为这些便利付费，仍需成交和后续行为验证。

年龄是试验范围，不是已证明的最优年龄；不据此排除其他成年年龄段的潜在需求。职业、收入、婚育状态、城市级别和消费能力都不能由年龄或点击推断。

### 3.2 画像矩阵

下表中的痛点、爽点、痒点及动机均为待访谈和数据验证的假设。

| 维度 | 具体描述 | 可观察证据 | 可能的反证 |
|---|---|---|---|
| 核心任务 | 记下开始、结束及个人备注；需要时找得到；购买适用用品 | 用户实际操作路径、真实购买经历 | 用户无需记录，也不想改变现有采购方式 |
| 日常场景 | 通勤、工作或居家间隙完成短操作 | 访谈中的最近一次真实经历 | 用户能接受现有复杂工具，省步骤没有吸引力 |
| 现有替代 | 手机日历、备忘录、经期 App；电商或商超采购 | 自述使用过什么、为何保留或放弃 | 原方案已经足够方便，迁移成本高于收益 |
| 痛点 | 输入麻烦、历史难找、补货重复比较、套餐规格不适合 | 放弃记录的具体环节、商品退换原因 | 所谓痛点没有频繁发生，未影响选择 |
| 爽点 | 快速完成记录；默认组合适用；价格与流程清楚 | 完成任务时间、选择修改次数、体验反馈 | 用户更喜欢自主选购，默认组合不省事 |
| 痒点 | 希望更了解自己的历史，希望感到被认真照顾 | 主动打开回顾、提出个性化需求 | 只是表达兴趣，没有后续使用或付费 |
| 品牌偏好 | 有常用品牌、日用／夜用等规格，接受有限替代 | 自愿填写偏好、选包及换包行为 | 大量用户只接受单一具体 SKU，组合难满足 |
| 决策标准 | 工具好用、商品适配、到手成本明确、领取取消方便 | 成交前问题、弃购反馈 | 用户只接受低于履约成本的价格 |
| 购买阻力 | 不清楚与现有工具的差别；担心用品用不上、领取麻烦 | 结算退出、咨询、取消及退款原因 | 解释清楚后购买意愿仍无改善 |
| 次期付费原因 | 记录积累、回顾有帮助、常用组合减少选购负担 | 次期使用、付费及访谈共同支持 | 仅首月优惠有效；有库存即取消；工具无使用 |

个人 AI 回顾需要足够、有效的历史记录。新用户短期没有使用回顾，不能直接判定其没有需求；应同时记录“是否已具备生成回顾的数据条件”，将可用性不足与用户不需要区分开。

## 4. 将画像转成可执行投放

| 层次 | 内容 | 边界 |
|---|---|---|
| 需求画像 | 省事、回顾、商品价值等动机 | 由访谈与行为验证，不能假设后台存在对应标签 |
| 实际广告定向 | 当前账户可用的年龄、地区及其他合规选项 | 记录后台真实名称、取值及版本；没有的维度留空 |
| 事后行为分组 | 是否完成记录、是否具备并查看回顾、是否领取、是否到期继续付费 | 仅说明已观察行为，不能直接推导收入、职业或健康状态 |

首轮地域按商品可达性、运费和售后能力确定。兴趣标签需在具体渠道账户核实后使用，不虚构“苏菲用户”“愿为省事付费”等现成标签。平台仅提供聚合年龄或地区报告时，保持聚合分析，不生成用户级人口属性。

经期日期、症状、个人备注及其他健康原始数据不回传广告平台。内部分析使用最少必要的行为事件和受控的去标识化关联；去标识化仍可能关联个人，不等于完全匿名。广告归因采用渠道允许且经核实的最小字段。

### 4.5 微信生态渠道与扩量(执行前补充)

LunaFlow 在中国大陆地区最常用的付费投放载体为腾讯广告(ADQ, ad.qq.com)统一后台下的若干资源位,不互相独立:朋友圈广告、视频号广告、公众号广告、搜一搜广告、小程序内广告。微信生态外延(优量汇、QQ、腾讯视频等)与上述版位共用同一套人群模型,但脱离小程序闭环,不推荐作主战场。

**首轮建议组合**:朋友圈广告(年龄 × 性别 × 地域)+ 公众号广告(底部 + 软文)。视频号因社交可见度高、经期类互动率偏低,不建议作首轮主投;小程序内广告主要服务站内复购,不作拉新主力。实际定向配置以投放时账户内可见项为准,本文给出的维度仅为投放前计划。

**扩量前置**:小样本定向无法直接扩量。需用首批 100-300 单实际付费用户的去重设备 ID / UnionID,在 ADQ 后台建 Lookalike(扩展人群)种子,跑 1%-5% 相似度档位。具体档位与种子规模下限以平台当期规则为准,执行前与 AM(广告平台客户经理)核实。

**智能出价前置**:oCPA(目标转化出价)需账户积累足够的成功转化样本作为学习依据(阈值因类目与广告主资质而异,执行前核实)。不满足阈值时先用基础出价跑通第一波,达到后再切,切换前数据作对照。

### 4.6 合规与素材前置(执行前补充)

卫生用品类目在微信广告审核中起充门槛与素材限制高于普通类目,具体数值以 ADQ 类目规则和当地广告法当期要求为准。素材与商品宣传需前置过审,避免使用"治疗""根治""消炎"等医疗术语,以及涉及具体功效的承诺表达。商品如涉及卫消证字或消字号,投放前先确认其有效性与平台类目匹配。

本文不替代合规审核,最终文案与商品上线以广告平台和监管的当期要求为准。

## 5. 多品牌权益如何降低选择成本

商品池可以多品牌，用户当次面对的选择保持少量：先确定常用品牌、规格偏好，展示一个推荐组合和两个替代组合；允许沿用上次选择，也允许修改。每个周期自行确认领取，不把默认选择当作自动领取。

| 组合方向 | 用途 | 展示要求 |
|---|---|---|
| 常用补给 | 满足已知日常规格偏好 | 品牌、具体 SKU、片数、尺寸、适用说明 |
| 规格调整 | 用户本期想调整日用／夜用等组合 | 与默认组合的数量和规格差异 |
| 便携搭配 | 用户认可的出行或随身补给选择 | 实际包含物、是否同价、是否有额外运费 |

以上是选品方向，不代表供应商已经签约。不得以品牌知名度代替供货确认，不假定每人每月消耗相同。对比价值采用同品牌同规格的可核实价格及明确条件，避免把限量券、附加消费门槛和虚高划线价算成无条件价值。

## 6. 首轮小预算验证

1. **先访谈 10—12 位自主采购用户。**询问最近一次采购、记录方式、放弃原因、用品库存和选择过程。展示相同套餐、价格及领取续费规则，观察理解和取舍。样本用于发现问题，不用于推算市场占比。
2. **先测诉求。**在相同基础投放范围内，比较“省事记录＋常用补给”和“个人历史回顾＋护理组合”两种素材。固定商品、价格、落地页主体和观察窗口；素材主要改变价值切入点。
3. **再测定向。**找到更有希望的诉求后，固定素材与套餐，比较基础范围和一个已核实的相关定向。优先使用平台支持的受控实验；存在人群重叠和分配偏差时，只作探索性比较。
4. **跨批次复测。**单次数据用于产生假设；另一批用户仍有类似结果后，再调整主定位和预算。

预算、可接受获客成本和停止条件在投放前写定，由可承受试错损失、毛利空间及供应能力决定，本文不指定未有依据的金额、保证订单数或转化率。前期只能观察首付和使用；月度留存须等相应账期与观察窗口成熟。

## 7. 最小数据字典

| 数据域 | 最小字段 | 来源与注意事项 |
|---|---|---|
| 广告 | 日期、渠道、计划／广告／素材 ID、实际定向配置、花费、曝光、点击 | 原始投放报表；保留统计口径和归因窗口 |
| 关联 | 内部去标识化用户 ID、允许使用的来源标识、首次来源时间、归因规则版本 | 无法关联记为未知，不能猜测来源或强行匹配 |
| 交易 | 订单 ID、用户 ID、套餐版本、实付金额、支付时间、交易类型 | 区分首次支付、自动扣款、用户主动发起再次支付 |
| 退款 | 原订单 ID、退款金额、发生时间、状态 | 挂回原交易及原用户批次；现金流另按实际退款日统计 |
| 订阅 | 首付日期、各期应付日期、到期状态、取消时间、扣款／续购结果 | 已取消者仍保留在其原批次的到期分母中 |
| 工具 | 必要的有效记录事件、回顾可用状态、回顾查看事件 | 仅记录分析所需事件，不复制健康原始内容 |
| 权益 | 权益周期、发放／生效、领取、券核销、订单及完成履约时间、失效原因 | 每个用户每期可关联一次权益；不适用环节留空 |
| 成本 | 商品、物流包装、支付手续费、AI、售后补偿、退货损失、待履约估计 | 保留实际值／估计值及更新日期；明确是否含税 |
| 访谈 | 自愿提供的采购习惯、购买动机及取消原因 | 与行为证据分开标注；不补造收入、职业等信息 |

所有数据保留统计截止日、时区和来源。未知值留空并注明缺失原因；缺失不等于零。

## 8. 指标与分母：统一后再比较

以同一首次付费批次为主线；每个批次使用相同观察时长。统一归因窗口，不把平台归因转化和后台自然成交直接相加。

微信广告默认归因窗口为「7 天点击 + 1 天展示」,对订阅类目可能短于真实决策周期。首付率、退款率、净付费率等主指标的口径以自有去重数据为准(投放 UTM + 用户 ID 关联),平台归因仅作辅助,不把"平台归因转化"与"后台自然成交"直接相加。归因窗口是否可调整、是否支持长决策周期类目,以 ADQ 当期类目规则和 AM 确认为准。

| 指标 | 计算口径 | 解读限制 |
|---|---|---|
| 首付 CAC | 对应广告花费 ÷ 归因去重首次成功付费新客数 | 分母包含之后退款者；同步单列退款及净付费人数 |
| 净付费人数／金额 | 截止时点，交易实付减退款后仍大于零的去重人数／金额合计 | 部分退款仍可能计入人数，因此金额必须同时展示 |
| 有效记录使用率 | 观察期内至少完成一次确认保存的有效记录任务人数 ÷ 同批获得工具访问权且使用观察窗口成熟人数 | 仅打开页面不算；按用户去重，不以填写字段多寡判断价值 |
| 可用回顾查看率 | 观察期内查看过已生成个人回顾的人数 ÷ 同批回顾已可用且查看观察窗口成熟人数 | 同时列出尚无足够历史、生成失败人数；不把技术问题归为用户无需求 |
| 到期付费留存 | 目标期净付费人数 ÷ 原批次中该期已到期且观察窗口成熟人数 | 自动扣款与主动支付均可计入，但分别列出；不删除取消用户 |
| 主动复购率 | 目标期用户主动发起且净支付大于零的人数 ÷ 同口径成熟到期人数 | 自动扣款、打开页面或领取权益不计作主动复购 |
| 权益领取率 | 已领取的用户权益期数 ÷ 同批有效发放且领取观察窗口成熟的权益期数 | 一人一期为一个单位；因退款失效等情况另列原因 |
| 券核销率 | 已核销券数 ÷ 同批已领取发券且核销窗口成熟的券数 | 只用于券类权益，不能与领取率混用 |
| 完成履约率 | 已完成履约的领取单数 ÷ 同批需要履约且履约观察窗口成熟的领取单数 | 实物领取、发货、签收分别记录；纯线上权益单独定义完成事件 |

每项的分子仅从对应分母所定义的同批成熟样本中计数。同时显示分子、分母、比例和截止日。例如“8／20”比单独显示“40%”更便于判断证据强弱；这仅是格式示例，并非真实投放结果。支付尝试失败后的宽限期、退款观察期及履约时限需事先统一，未成熟数据标为待观察。

退款分析归回原订单和原批次，避免让后来的批次承担早期退款；同时保留按退款发生日统计的现金流。尚未结束的退款窗口可能改变净付费结果，不能提前当作最终值。

## 9. 用成本后贡献判断人群价值

同批次成本后贡献估计：

**净收款 − 商品及包装物流 − 支付手续费 − AI 与其他可归属服务成本 − 售后、退货及补偿成本 − 待履约成本估计 − 对应获客支出。**

已退款金额在净收款中扣除，不再次作为费用重复扣减；退款引起的不可退手续费、退货损失等单独计入。已发生履约成本与待履约估计按订单状态衔接，避免重复扣减。税费、共享运营成本和固定成本是否计入须明确，因此该指标不能直接称作公司净利润。

未领取可能降低实际履约支出，但仍有数字服务、客服、支付、退款和其他成本；未到期权益还可能产生履约义务。不能把未领取收入直接当成纯利润，也不能用短期预收现金代替已验证的长期收益。

## 10. 防止把偶然结果写成精准画像

- 小样本仅作线索，不因几笔成交宣布某年龄或地区“最优”。
- 预先限定主要比较维度；大量切分年龄、城市、素材和套餐容易偶然找到高值。
- 同时检查价格、素材、履约、归因及观察期差异，避免全部归因为人群本身。
- 比较金额、样本量、退款和成本后贡献，不只看点击率或 GMV。
- 新批次复测后再收窄；保留一定探索空间，避免早期偏差持续放大。

## 12. 下一步需要的数据
